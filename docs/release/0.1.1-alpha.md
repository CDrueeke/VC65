# VC65 0.1.1-Alpha (Vorabversion)

**Deutsch** · [English below](#english)

## Was das ist
**Sprache:** Das Programm VC65 (Oberfläche, Meldungen, Debugger) ist nur auf Englisch; Dokumentation und Webseite gibt es auf Deutsch und Englisch.

VC65 ist eine native Entwicklungsumgebung für den MEGA65: Editor, VCASM-kompatibler Assembler und Debugger laufen auf dem MEGA65 selbst, ohne PC. VC65 übersetzt Quelltexte in VCASM (Schwesterprojekt: VintageCoder) und startet das Ergebnis.

## Neu in 0.1.1-alpha
Fehlerkorrekturen gegenüber 0.1.0-alpha, Funktionsumfang unverändert:
- **Startbild und File > About:** Der Quelltext schimmert nicht mehr durch das Logo (er wird abgedunkelt).
- **Debugger:** Haltepunkte gelten nur für den zuletzt übersetzten Text und werden bei einer Textänderung gelöscht; vorher konnte ein BRK mitten in einem Befehl landen (Anzeige `brk`, Programm entgleist, Haltepunkt übersehen). Nach einem regulären Programmende bleiben keine Reste in der Haltepunkttabelle.
- **Beispiele und Tutorial** ohne `.cpu`: 45GS02 ist der Standard (die Direktive wird weiterhin gelesen und ignoriert; Ausgabe byte-gleich).
- **Handbuch und Release** zeigen echte Aufnahmen aus Xemu; Vorlage für Pull Requests.

## Wichtig: nur im Emulator getestet
Diese Vorabversion wurde **ausschließlich im Emulator Xemu** geprüft (Mac und Windows-Gegenprobe). Am echten MEGA65 ist **nichts** geprüft. Ungeprüft am Gerät sind insbesondere: HELP-Taste (Code `$84`) und Menü, 50-Zeilen-Bild und Farben, Laden der Dateien `VC65T`/`VC65X`/`VC65D` von der Disk, zwei Disks (Laufwerk 8/9), die Notfalltaste (RESTORE), die automatische Prüfung bei Zeilenwechsel und die Geschwindigkeit auf Hardware. Die Liste steht in [`docs/entwickler/de/handtest.md`](../entwickler/de/handtest.md). Rückmeldungen vom echten Gerät sind willkommen.

## Inhalt
- **Editor** (80 × 50): Färbung, Zeilennummern, Auswahl, Kopieren, Rückgängig, Suchen/Ersetzen, Gehe zu, Marken 1–9, Label suchen, Ausrichten in Spalten, Hex-Rechner, Daten einfügen; Menü über die HELP-Taste; Dateizeile, Probleme-Leiste, Statuszeile. **Eine** Datei (keine Reiter).
- **Assembler**: übersetzt sich selbst byte-gleich zu `vcc` (in Xemu); Stufen 1 und 2 von VCASM weitgehend; MEGA65-Systembibliotheken von der Disk; Fehlerliste, Fehlerzeilen rot; **automatische Prüfung** bei jedem Zeilenwechsel nach einer Änderung (Texte unter 16 KB).
- **Bauen und Starten**: Strg+E, Strg+F (Programm speichern), Strg+R (starten), Rückkehr in die IDE.
- **Debugger**: Haltepunkte, Einzelschritt, Register, Speicher, Notfalltaste.
- **Handbuch** (Deutsch und Englisch, ausführlich mit Anleitung, Beispielen, Fehlersuche, Fehlercodes und Glossar): als PDF und als Markdown-ZIP mit Bildern als Anhänge des Releases; Quelle: [`docs/benutzer`](../benutzer/de/README.md).

## Bekannte Grenzen
- Nur Ziel `mega65`; kein C64-Ziel. `.target` ist optional.
- Keine Haltepunkte in Makrorümpfen, keine Beobachtungen oder Datenhaltepunkte, keine Haltepunkte im ROM-Bereich.
- Nicht unterstützt: `.atascii` und `.cartridge` (bewusst, nur MEGA65), Systemdateien anderer Ziele und Medien-Includes (`.vcsprite` usw., E219). `.segment` prüft nur Namen und Bereich; `.bank` kennt nur Bank 0 (sonst E901).
- Keine Ordner und langen Dateinamen (Hyppo-Zugriff folgt), keine Projektdateien `.vcprj`, kein Sichern von VC65 selbst auf die SD-Karte.
- Umlaute und andere Nicht-ASCII-Zeichen nur in Kommentaren und in Zeichenketten für `.text`, `.petscii`, `.byte`: in Labels, Konstanten und Zeichenliteralen meldet VC65 Fehler (`vcc` nimmt sie an), `.screencode` weicht ab.
- Makros haben höchstens 16 Parameter (E900; `vcc` kennt keine Grenze).
- Der Platz unter `$D000` ist knapp; größere neue Funktionen brauchen weitere Auslagerung.

# VC65 0.1.1-alpha (pre-release)

## What it is
**Language:** The program VC65 (user interface, messages, debugger) is English only; documentation and website are available in German and English.

VC65 is a native development environment for the MEGA65: editor, VCASM-compatible assembler and debugger run on the MEGA65 itself, without a PC. VC65 assembles sources written in VCASM (sister project: VintageCoder) and runs the result.

## New in 0.1.1-alpha
Bug fixes compared with 0.1.0-alpha; feature set unchanged:
- **Start screen and File > About:** the source text no longer shows through the logo (it is dimmed).
- **Debugger:** breakpoints apply only to the text as last assembled and are cleared when the text changes; before, a BRK could land in the middle of an instruction (display `brk`, the program derailed, a breakpoint was missed). After a normal program end no leftovers stay in the breakpoint table.
- **Examples and tutorial** without `.cpu`: 45GS02 is the default (the directive is still read and ignored; output byte-identical).
- **Manual and release** show real captures from Xemu; pull request template.

## Important: tested in the emulator only
This pre-release was checked **only in the Xemu emulator** (Mac, with a Windows cross-check). **Nothing** has been checked on a real MEGA65. Unchecked on the device in particular: the HELP key (code `$84`) and the menu, the 50-row screen and colours, loading the files `VC65T`/`VC65X`/`VC65D` from disk, two disks (drive 8/9), the emergency key (RESTORE), the automatic check on line change and speed on hardware. The list is in [`docs/entwickler/en/handtest.md`](../entwickler/en/handtest.md). Reports from a real device are welcome.

## Contents
- **Editor** (80 × 50): colouring, line numbers, selection, copy, undo, find/replace, go to line, marks 1-9, find label, align in columns, hex calculator, insert data; menu on the HELP key; file line, problems panel, status line. **One** file (no tabs).
- **Assembler**: assembles itself byte-identical to `vcc` (in Xemu); levels 1 and 2 of VCASM largely; MEGA65 system libraries from disk; error list, error lines in red; **automatic check** on every line change after an edit (texts under 16 KB).
- **Build and run**: Ctrl+E, Ctrl+F (save program), Ctrl+R (run), return to the IDE.
- **Debugger**: breakpoints, single step, registers, memory, emergency key.
- **Manual** (German and English, detailed with tutorial, examples, troubleshooting, error codes and glossary): as PDF and as Markdown ZIP with images, attached to the release; source: [`docs/benutzer`](../benutzer/en/README.md).

## Known limits
- Target `mega65` only; no C64 target. `.target` is optional.
- No breakpoints in macro bodies, no watches or data breakpoints, no breakpoints in the ROM area.
- Not supported: `.atascii` and `.cartridge` (deliberately, MEGA65 only), system files of other targets and media includes (`.vcsprite` etc., E219). `.segment` checks only name and range; `.bank` knows only bank 0 (otherwise E901).
- No folders and long file names (Hyppo access to follow), no `.vcprj` project files, no saving VC65 itself to the SD card.
- Umlauts and other non-ASCII characters only in comments and in strings for `.text`, `.petscii`, `.byte`: VC65 reports errors for them in labels, constants and character literals (`vcc` accepts them), `.screencode` differs.
- Macros have at most 16 parameters (E900; `vcc` has no limit).
- Space below `$D000` is tight; larger new features need more offloading.
