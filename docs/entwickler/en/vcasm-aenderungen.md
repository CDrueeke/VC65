# VCASM changes and status in VC65

German version: [../de/vcasm-aenderungen.md](../de/vcasm-aenderungen.md). VintageCoder owns the language description; VC65 reconciles before every release. The main session reports every change to the assembler (vc-asm, `data/asm`, `data/sys`, `data/targets`) the same day with commit and classification: (a) changes behaviour/output of existing sources, (b) addition (new directive, function, syntax, message), (c) rename/alias only (old names stay valid), (d) docs/examples only. Reconciliation baseline in VC65: vcc `2caec744` (since 2026-11-23, before that `222113b4`).

## Open points
- Reconciliation against vcc `2caec744` is done (2026-11-23): 32 differential tests, conformance 61 of 67, error list, include, cycles, self-compilation, line table (except the known macro differences) identical; `tools/vcc.version` is at `2caec744`.
- Open: `.atascii`, `.bank`, `.segment`, `.cartridge` (target/segment directives) do not exist in the native assembler; W205 and W207 do not apply to the MEGA65.
- Locations: `assets/docs/Konzept-VCASM-Direktiven-Benennung.md`, `Konzept-Include-von-Medien.md`, help pages `crates/vc-ide/help/asm-directives.md` and `asm-*.md`, source `crates/vc-asm/src/{lib,tree}.rs`, test `crates/vc-asm/tests/media_include.rs`.
