# VC65-Logo

Das Logo ist der Entwurf des Inhabers: Wortmarke „VC65.“ in **JetBrains Mono Bold** (als Pfade, keine Schrift nötig), „VC“ violett, „65“ weiß, der Punkt gelb. Die Dateien hier nicht von Hand ändern.

| Datei | Verwendung |
|---|---|
| `vc65-icon.svg/.png` | App-Icon: Wortmarke auf dunkler, abgerundeter Kachel |
| `vc65-wortmarke.svg/.png` | Wortmarke „VC65.“ auf dunklem Grund |
| `vc65-vc.svg/.png` | Kurzmarke „VC“ |

Schreibweise: **VC65** (Großbuchstaben, ohne Leerzeichen). Der gelbe Punkt gehört zum Logo. Das Logo darf als Verweis auf VC65 (Referenz) verwendet werden, zum Beispiel neben einem Link oder in einer Quellenangabe, auch skaliert oder einfarbig; sonst nicht verändert, nicht als Zeichen eines anderen Produkts, nicht mit dem Eindruck einer Zugehörigkeit oder Billigung. Der Name „VC65“ gilt nur als wahrheitsgemäße Herkunftsangabe (siehe `LICENSING.md`).

Darstellung im Programm (MEGA65): Der Textbildschirm kann kein Vektorlogo zeigen; die IDE zeigt das Logo als farbige Zeichenzellen in der Menüleiste („VC“ lavendel, „65“ weiß, „.“ gelb).
